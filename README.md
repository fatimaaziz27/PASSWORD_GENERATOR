# 🔐 PASSWORD_GENERATOR

A simple console-based **Password Generator** implemented in multiple programming languages. This project generates strong, random passwords using letters, numbers, and special characters, helping users create secure passwords for their accounts.

---

## Features

- Generate random passwords
- User-defined password length
-

- Java
- C++
- JavaScript

## Repository Structure

| File | Description |
|------|-------------|
| `PasswordGenerator.py` | Python implementation |
| `PasswordGenerator.java` | Java implementation |
| `PasswordGenerator.cpp` | C++ implementation |
| `PasswordGenerator.js` | JavaScript implementation |

---

## Purpose

This project was created to practice programming fundamentals, random number generation, string manipulation, and user input handling across multiple programming languages while building a practical security-related application.
